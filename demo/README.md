# Demo Assets

This folder contains small committed demo captures and their source tapes.

## Committed Assets

- `*.tape`: source scripts for demo recordings.
- Small `*.gif` files: checked-in product/demo captures referenced by docs or
  useful for quick review.

## Local Generated Assets

Use `demo/generated/` for large render exports, optimized social GIFs, MP4s, and
alternate cover candidates. That directory is ignored by git so the repo root
does not fill up with heavy generated files.

If a generated asset becomes canonical documentation or launch material, move it
into `docs/assets/` or a named durable report bundle and update the relevant
README.
