# Demo share page, 2026-10-13

A one-page Vercel site at https://edgarpack-demo.vercel.app that plays the EdgarPack demo. Deploy it with `vercel --prod` from this folder.

Link previews (added 2026-10-23): `og.mp4` is a 4.3-second, 56 KB loop of the closing title card from 40 s, where the icon drops in and "Shrinking context to get real work done" types in. iMessage plays it in place of a still. `og.jpg` is the settled card, used by X, Slack and LinkedIn, which ignore `og:video`. Both are 1200x630, and `og.mp4` is gitignored. The recipe is in Phoenix's `design-engineering-craft` skill, "For share pages".
