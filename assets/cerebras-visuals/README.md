# Edgarpack Cerebras S-1 Thread Graphics

Canvas: 1600 x 900 PNG and SVG. Designed for X/Twitter thread cards.

Design palette:
- Warm paper: #F7F1E6
- Ink: #111723
- Graphite: #3E4249
- Muted green: #8EA37A
- Copper: #B46B4D
- Playdate yellow accent: #FFD95A

Visual ethos: primary-source, calm, rigorous, minimal, generous whitespace, one point per figure. Inspired by Cursor-like diff/editor surfaces and Playdate-like friendly hardware geometry.

Notes:
- Text labels use the supplied tweet-thread facts.
- Footers intentionally avoid raw URLs for a cleaner social look.
- SVGs use system font-family references rather than embedded fonts.
