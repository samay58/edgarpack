# S-1 Guide

Use this when a company has filed to go public but has not filed a 10-K yet.

## Build the pack

If you know the company name:

```bash
edgarpack build "Neutron Holdings" --form S-1 --with-chunks
```

If you know the exact filing:

```bash
edgarpack build "Cerebras Systems" \
  --accession 0001628280-26-029503 \
  --form S-1/A \
  --with-chunks \
  --force
```

Use `--force` when you want to rebuild the local files.

## See what EdgarPack found

```bash
edgarpack which "Neutron Holdings"
```

This shows:

- S-1 financial metrics that can be queried.
- Places in the filing that may contain operating metrics.
- Market-size claims.
- Use of proceeds, dilution, lockup terms, and major holders when found.

If KPI discovery cannot run, the command still shows S-1 disclosures found by
rules and says the KPI step can be retried.

## Query financials

For the latest full year:

```bash
edgarpack query "Neutron Holdings" --period lfy
```

For two years:

```bash
edgarpack query "Neutron Holdings" \
  revenue,gross_profit,operating_income,net_income,operating_cash_flow,adjusted_ebitda \
  --period lfy,lfy-1
```

Common S-1 metrics:

- `revenue`
- `gross_profit`
- `gross_margin`
- `operating_income`
- `operating_margin`
- `net_income`
- `net_margin`
- `operating_cash_flow`
- `capex`
- `free_cash_flow`
- `adjusted_gross_profit`
- `adjusted_ebitda`
- `cash_and_equivalents`
- `total_assets`
- `stockholders_equity`
- `shares_outstanding_basic`
- `eps_basic`

`adjusted_ebitda` is separate from `ebitda`. EdgarPack will not treat one as
the other.

## Read the output

Each number should have a citation like `[C1]`.

If a metric is `N/A`, it means EdgarPack did not find a cited value for that
metric in the local S-1 pack. It is not an estimate.

If a filing has tables that are hard to parse, rebuild the pack and run:

```bash
edgarpack which "Company Name" --no-cache
```

Then query only the metric you care about:

```bash
edgarpack query "Company Name" revenue --period lfy,lfy-1
```

## Good examples

```bash
edgarpack query "Neutron Holdings" --period lfy
edgarpack query "Cerebras Systems" --period lfy
edgarpack which "HawkEye 360"
```
