section_diff._compute_section_intensity()
Cache hit vs miss SHA256 fingerprints at two levels: disk cache skips re-fetching from SEC, paragraph fingerprints short-circuit identical text before expensive Jaccard computation. Two cache layers, zero wasted diff cycles.
cache.py + text_diff.py fingerprint fast-path

No LLM in the loop. Deterministic hashing, pattern-based topics, and word-weighted scoring produce reproducible results. Same filings in, same insights out.
