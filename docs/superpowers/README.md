# Design Session Archive

This folder stores structured specs and execution plans from prior design
sessions. It is useful historical context, not the live issue tracker.

## Layout

- `specs/`: approved design summaries, product decisions, and architecture
  reasoning.
- `plans/`: execution checklists and implementation plans generated from those
  specs.
- `scrub-2026-04-15.md`: historical cleanup notes.

## How To Use

Start with `docs/BACKLOG.md` and repo docs first. Use these files when
you need to understand why a feature exists, what tradeoffs were accepted, or
which older plan an issue references.

Do not treat old plans as active work unless current work explicitly
revives them.
