# Packet: build-hk-construct

Goal: `edgarpack build-hk <ticker-or-code>` builds an HKEX pack for any cleanly-extractable listed issuer: acquire the English annual report (module already shipped in build-hk-acquire), section it via TOC-page slicing, extract facts, and write a manifest whose currency/standard come from the filing itself. The hardcoded `_COMPANY_META` dict dies.

Files owned: `edgarpack/hk/adapter.py` (rework), new `edgarpack/hk/toc.py` (TOC parser + page slicer), `edgarpack/hk/sections.yaml` (keyword map additions), `edgarpack/hk/acquire.py` (ONLY `extract_filing_metadata`, extending anchor shapes), `edgarpack/cli.py` (new `build-hk` parser + `_cmd_build_hk` only), tests + text fixtures under `tests/fixtures/hkex_toc/`.
NOT owned: `edgarpack/hk/extract.py` (hk-extract-fixes packet, running in parallel; consume its interface unchanged: `extract_facts_from_pack(pack_dir)` over `sections/*.md`, and its typed `HKExtractionBlockedError` when it lands: catch it and fail the facts step loudly while still writing the sectioned pack).
Evidence: the hk-construct-prototype report (all page numbers and title variants below are from real FY2025 ARs of Tencent, Meituan, BYD, Anta, HSBC; prototype scripts under session scratchpad `hk-construct-prototype/` are working reference code).

## Pre-made design decisions (from prototype evidence)

- **TOC parser** (`hk/toc.py`): handle both shapes: leading page number (`129 CONSOLIDATED INCOME STATEMENT`) and trailing (`Consolidated Income Statement 211`). Two mandatory extensions the prototype proved necessary: (1) continuation-line joining: a line with no leading/trailing page number of its own appends to the previous entry's title (fixes Anta's four truncations, two of which made different statements title-identical); (2) printed-page-to-pdf-index resolution by ANCHOR SEARCH, not formula: verified offsets were 0, +1, and -1 across issuers, so for each TOC entry search a narrow window around the naive index for the entry's own title text and take the first match. Bilingual TOC lines (BYD: English then Chinese on one line) keep the English capture.
- **Section slicing**: slice pages at TOC boundaries into `sections/*.md` (pypdf text, NOT pymupdf4llm, per spike verdict), mapping titles through the keyword map. Keyword additions the prototype pinned: `CONSOLIDATED INCOME STATEMENT` -> hkex_income_statement (three of five issuers use it; the current map's biggest gap); singular `CONSOLIDATED STATEMENT OF PROFIT OR LOSS AND OTHER COMPREHENSIVE INCOME` -> hkex_income_statement (Anta's combined-statement form); singular `CONSOLIDATED BALANCE SHEET` -> hkex_balance_sheet (BYD). BYD's PRC-statutory parent-company-only statements (same titles WITHOUT the "Consolidated" prefix) are a different reporting entity: map them to nothing (skip), with a comment.
- **Coarse-TOC fallback**: when the TOC yields no per-statement entries (HSBC pattern: one "Financial statements" chapter), run one in-page heading pass inside that chapter's page range before giving up. If statements still cannot be located, fail the sectioning step with a typed error naming what was found.
- **Metadata**: extend `extract_filing_metadata` with the two additional anchor shapes the prototype found: the repeated page-header parenthetical (`(Expressed in Renminbi unless otherwise indicated)`, Anta) and the numbered reporting-currency note (BYD CAS form), and widen the search to the whole document (Anta's policy note sits a full section after the statements). CAS is a valid existing AccountingStandard value; BYD-class filers get CAS. Joint citations ("IFRS ... and HKFRS ...", Anta) normalize to IFRS with the joint form noted in the manifest. Both-anchors-missing stays a typed error, no defaults. `_COMPANY_META` is deleted; the manifest fields come from `extract_filing_metadata` + the search response (short name) + the cover page (legal name, best-effort). Note: this corrects Tencent/Meituan from the legacy dict's HKFRS to their filings' stated IFRS; the committed MiniMax/Zhipu fixture packs keep their existing manifests (not rebuilt), so china goldens are unaffected.
- **Pack shape**: existing HK pack layout and facts.json contract unchanged, plus one OPTIONAL manifest field `dual_counter_codes` (list; from the search row's `<br/>`-joined STOCK_CODE; absent when single-counter, e.g. HSBC). DOD_WEB_PATH is ignored (empty across every AR row of six issuers). Results announcements: nothing in v1.
- **CLI**: `edgarpack build-hk <company>` resolves via identity/universe or a bare 5-digit code, acquires (staleness floor and English selection live in the acquire module), builds, extracts facts, prints the pack path and a facts summary. `--accession`-style pinning is out of scope for v1 (acquire selects latest; note it in --help). Lazy-startup invariant holds.
- **v1 scope line**: cleanly-extractable filers only. A garbled filing (HSBC-class) produces the sectioned pack plus a loud typed facts-step failure, never guessed values. OCR is a separately-scoped follow-up.
